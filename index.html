The approach

I want one aim across everything I play — hipfire and scoped, in Overwatch, CS2, Valorant, and Apex. The rule that makes that possible: match everything at 0% monitor distance, i.e. 1:1 at the crosshair, where aiming actually happens. Scoped sens is matched to hipfire within each game, and hipfire is matched across games the same way.

One sanity check before trusting any conversion: the resulting eDPI (sens × DPI) has to land inside the range most pros run in that game. My base is Overwatch, 2.28 at 1600 DPI — converted at 0%, every game does:

That's no coincidence: pros in wide-FOV games naturally run higher eDPI, which is exactly what a 0% conversion predicts. Keeping cm/360 instead would put me below the Apex pro average — the two methods disagree by 27% there. The next sections unpack the math.

sens₂ = sens₁ × (yaw₁ / yaw₂) × tan(F₂⁄2) / tan(F₁⁄2)

Why 0%, and not cm/360 or the screen edge

Scoping reduces your FOV, so the same mouse movement covers more screen distance. Every game has a setting that compensates — Overwatch's per-hero Relative Aim Sensitivity While Zoomed, CS2's zoom_sensitivity_ratio, Valorant's scoped sensitivity multiplier, Apex's per-optic ADS multipliers. At the right value, you move your mouse the same distance to reach a target on screen whether you're scoped or not. That's “1:1”. The catch: which target?

Your mouse maps centimeters to degrees of rotation, a fixed number of degrees per cm, regardless of FOV. But your flat monitor maps degrees to pixels through a tangent:

screen position = distance × tan(angle)

The tangent grows faster and faster as the angle increases, so the screen edges are “stretched”: one degree of rotation near the crosshair moves the image only a few pixels, while one degree near the edge moves it many. Equal angles, unequal pixels.

Because of that stretch, there are three defensible ways to “match” two views (scoped vs hipfire, or game vs game) — and they give different numbers:

  • Same cm/360 — the same physical mouse distance for a full turn. Preserves full-turn flicks and general movement, but ignores FOV entirely: the identical wrist flick covers different screen distance in each view.
  • 100% monitor distance (linear FOV ratio) — the same mouse distance to reach the screen edge. This is what CS2's and Valorant's defaults do. But the edge is the most stretched, least relevant part of the screen — matching there makes everything near the crosshair run fast.
  • 0% monitor distance (tangent ratio) — the same on-screen speed at the crosshair. Micro-adjustments, tracking, and duels all happen at the crosshair, so this is the match point that makes scoped aim feel like hipfire. It's also the one Apex ships as its default.

No single value is 1:1 everywhere on a flat screen — you pick a point. I pick the crosshair.

The formulas

Let F₁ = hipfire horizontal FOV, F₂ = scoped horizontal FOV, and p = monitor-distance fraction (0…1), both FOVs in the same aspect ratio.

Linear / FOV-ratio = 100% monitor distance

sens% = (F₂ / F₁) × 100

Tangent (“true 1:1”) = 0% monitor distance

sens% = ( tan(F₂⁄2) / tan(F₁⁄2) ) × 100

General: exact 1:1 for a target at monitor distance p

sens%(p) = ( atan( p·tan(F₂⁄2) ) / atan( p·tan(F₁⁄2) ) ) × 100

As p → 0 this reduces to the tangent method; at p = 1 it equals the linear method. Every table and chart on this page is computed from these three lines (the cross-game calculator adds only each game's yaw constant).

CS2

The default zoom_sensitivity_ratio 1 matches at the edge of a 4:3 screen, which on a 16:9 monitor (106.26° hipfire FOV) is 75% monitor distance. A 0% (crosshair) match instead needs

zoom_sensitivity_ratio = (F1 / F2) × tan(F2/2) / tan(F1/2)

with FOVs in 4:3 degrees (hipfire F1 = 90°). One console variable covers every weapon and zoom level, so you pick which zoom to be exact for. The community standard 0.818933 is exact for the first zoom of the AWP and SSG 08; the other zooms land within about 4% of it.

Apex Legends

Apex is the odd one out: it scales ADS sensitivity by the focal-length (tangent) ratio, so the default multiplier of 1.0 is already an exact 0% monitor-distance match for every optic, at any FOV and aspect ratio. Leave the ADS multiplier and every per-optic slider at 1.0 and you're done.

The optic FOVs come from the game files, tuned to exact magnifications at 70 FOV (the configs literally say "38.5907" // 2x @ 70). Raising the FOV setting scales the ADS FOV linearly in degrees, but your screen maps tangents, so the effective magnification grows with FOV — the table shows the effective zoom at 100 FOV. Variable optics toggle between two tiers (1x–2x, 2x–4x, 4x–8x, 4x–10x), each tier using its own in-game per-optic slider.
